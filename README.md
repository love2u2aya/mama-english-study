# ママえいご (Mama English) 🦉

日本語話者のための、Duolingo風 英語学習アプリ。まずは小さく始めるMVPです。

## できること（MVP）

- ホームに「スキルの道」（ジグザグのレッスンノード）
- レッスン内の問題タイプ
  - **4択**（意味を選ぶ）
  - **単語の並べ替え**（英文をつくる）
- ライフ（ハート）❤️ … 間違えると減る／切れたら回復モーダル
- 経験値（XP）⚡ と 連続学習日数（ストリーク）🔥
- 進捗・状態は `localStorage` に自動保存
- 画像が無くても絵文字で動作（画像は後から差し替え）

## 技術

- 依存ライブラリなし。**素のHTML / CSS / JavaScript** のみ。
- ビルド不要。`index.html` を開くだけで動きます。

## ローカルで開く

```bash
# どれでもOK
python3 -m http.server 8000
# → http://localhost:8000
```

## ファイル構成

```
index.html   … 画面の骨組み
styles.css   … Duolingo風スタイル
data.js      … レッスン・問題データ（ここを増やせば学習内容が増える）
app.js       … アプリ本体（画面遷移・採点・状態保存）
assets/      … 画像（CODEXに依頼。README_IMAGES.md 参照）
```

## 画像について

画像は CODEX に依頼します。必要な画像の一覧と仕様は
[`assets/README_IMAGES.md`](assets/README_IMAGES.md) を参照してください。
